# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| main branch | Yes |

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: hello@automatelab.tech

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive a response within 72 hours. If the issue is confirmed, a fix will be prioritized and a patched release coordinated before public disclosure.

## Scope

This repo contains Claude Code skills and a Notion integration. Credentials (API keys, Notion tokens) should be stored in `.env` (gitignored). Never commit secrets to this repo.
